# Gestion des Affectations

Application web Java EE pour gérer les employés, lieux et affectations.

## Technologies utilisées
- Java 17/21
- Hibernate 5.6
- MySQL 8
- JSP / Servlets
- Tomcat 9
- Maven

## Fonctionnalités
- CRUD sur les employés, lieux et affectations
- Recherche automatique multi-critères
- Design moderne et responsive

## Installation
1. Cloner le projet :
   ```bash
   git clone https://github.com/odonardo/Gestion-affectations.git

## Configuration
